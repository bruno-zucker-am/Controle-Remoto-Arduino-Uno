# Controle-Remoto-Arduino-Uno
Controle remoto infravermelho com Arduino Uno: captura códigos IR (protocolo SONY), envia comandos de TV digitados no monitor serial e liga/desliga a TV por gesto com sensor ultrassônico HC-SR04. Código modular, com autotestes na inicialização. Validado só no hardware físico, sem simulador.
